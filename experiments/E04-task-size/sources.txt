  -> The host kernel is aarch64 (Docker Desktop VM); the 386 binary runs under
  qemu-user, which virtualizes /proc/self/maps to guest-side entries in its own
  synthetic layout (top = 0x408ac000, [stack] at 0x40001000). This reflects
  qemu's layout policy, NOT an x86_64 kernel's compat TASK_SIZE, and an
  aarch64 kernel has no ia32 compat mode at all. Result discarded as distorted;
